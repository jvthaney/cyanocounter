What a link means, and what it does not

A link means the rules make feeding physically possible: the food falls inside the consumer's size window and is not a filament or a large colony. It does not mean the interaction has been observed. Size rules over-predict, so treat the web as a set of candidate links to check, not a finding. A taxon with no body length in the trait table cannot be linked at all and is drawn without edges.
