Plankton Counters and Food Web Tools

Tools for counting plankton in your own lake, and for using those counts to build a food web.

Cyano Counter

Cyano Counter: Counters for cyanobacteria, with common taxa and identification cards. Built for community science monitoring projects, including the Lake Sunapee Protective Association.

Food Web Counter

Food Web Counter: Count plankton, or anything else. Counters record whether it is phytoplankton, zooplankton, or other taxa. For phytoplankton, designate whether you counted cells, colonies, or filaments. Send the finished count straight to the dashboard, or export it as a spreadsheet.

Food Web Dashboard

Food Web Dashboard: Turn taxonomic count data into a lake food web. Taxa appear as nodes connected by links representing feeding relationships. Edit the counts, add or remove taxa, change the feeding rules, and watch the food web change shape.

These tools are early versions. The trait data behind the food web are still being assembled, and tools are still being tested, so results should be treated as a first draft. The tools accompany the Image-Based Key to the Zooplankton of North America from the UNH Center for Freshwater Biology.
