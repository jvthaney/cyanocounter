Count plankton and other taxa

Counts can optionally be sent to the Food Web Dashboard to build a food web



  • 1. Enter your metadata above and click Submit info.
  • 2. Add counters:
    • Phytoplankton: Click Add phytoplankton + --> Enter taxon name --> Select whether you are counting cells, colonies, or filaments --> Begin counting.
    • Zooplankton: Click Add zooplankton + --> Enter taxon name --> Begin counting.
    • Other taxa: Click Add other + --> Enter taxon name --> Begin counting.
  • 3. When done, you can:
    • Click Download spreadsheet to download the data to your computer.
    • Click Send to Food Web Dashboard to build a food web from these counts and open the dashboard in a new tab.
